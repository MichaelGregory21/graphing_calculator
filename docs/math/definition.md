# Definitions

A definition is an assignment of an set, an expression, or a condition to a global variable.

---

## 1. Types of Definitions

There are two type of definitions in the system. These are `=` and `<-`.

`<-` assigns the right object to the left variable without attempting to plot the object.

`=` assigns the right object to the left variable and attempts to plot the object.

Conditions may not be defined using `=`.
